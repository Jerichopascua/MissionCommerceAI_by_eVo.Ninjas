## Non-negotiables (one glance)

1. A meaningful part of the workload **runs on AMD** (Developer Cloud / Instinct / ROCm / Ryzen AI / Radeon) — and it's visible in the demo.
2. Product turns customer/business data into a **recommendation or action**.
3. If we predict demand/sales/behaviour → **explain how**; an LLM must **not** be the only forecasting method.
4. Show a **measurable effect** (revenue, margin, conversion, retention, inventory, or service quality).
5. Public GitHub repo, working prototype, demo video, slide deck, cover image.
